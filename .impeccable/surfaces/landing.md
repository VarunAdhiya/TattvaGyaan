# Landing page

Mode: Persuade. Route: `/`. Scope: a new homepage inside the existing visual
identity; book readers, login forms and data imports are outside visual scope.

## Direction contract

- FORM: user-pinned temple-background homepage, informed by the reference site's
  category navigation and Panchang. No concept roll: the supplied background
  and existing app identity establish the direction. 12ui draft was attempted
  but returned an authentication requirement; no generated comp exists.
- OWN-WORLD: the user's riverside temple at sunset is the dominant image. Warm
  ivory text, restrained saffron actions, parchment supporting sections, and
  a deep green scripture section extend the photograph's colors.
- STRUCTURE: hero/navigation, current Panchang strip, editorial devotional
  index, scripture introduction, quiet closing invitation, existing footer.
- INTERACTION: real route links, mobile menu with keyboard dismissal, public
  home for both guest and authenticated visitors, calendar data from the API.
- TRUTH: no fabricated readings, dates, testimonials, source credits, or usage
  counts. Absent calendar data has an explicit fallback. Ramayan is described
  as the comparative study actually in the library.

## Quality bar

The supplied image must remain visibly dominant, with the temple readable on
desktop and mobile. Typography and overlays must keep foreground copy legible.
Self-host Cormorant Garamond for the display voice; use existing body fonts.
Avoid equal-sized promotional cards. Mobile content reflows without overflow.
Verify hero, full page, navigation, empty/error calendar states, and auth paths.
