# HinduAarti reference evidence

Source: https://www.hinduaarti.com/  
Inspected: 20 October 2026.

The browser inspection observed Cormorant headings, Inter body text, a Noto
Devanagari face and a dark `#0f121a` body background. The captured reference is
`../review/hinduaarti-reference.png`.

The dashboard adapts the continuous dark ground, restrained serif headings,
readable supporting copy and image-led devotional composition. Its implemented
ground is warmer (`#191715`), with Hind interface text and local project content.
Durga, Ganesha, Hanuman, Krishna and Shiva artwork remains complete and unblurred.
Reference branding is not part of the application UI.

No generated design composition was available: the 12ui service required an
external login. Implementation used the inspected reference and supplied assets.
The actual implementation is recorded in `../../DESIGN.md` and
`../surfaces/dashboard.md`; the reference is evidence, not a replacement source
of project tokens or devotional content.
